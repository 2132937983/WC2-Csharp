# Authored game data

**Language / 语言:** [English](#english) | [中文](#chinese)

<a id="english"></a>

The JSON game data (field reference: `DATA_SCHEMA.md` in the repository root). These files are the
source of truth; the original XML they were converted from stays untouched in `../xml/`. Mods merge
into them (`MODDING.md`). Markdown files are not packaged.

---

<a id="chinese"></a>

# 编写的游戏数据

JSON 格式的游戏数据（字段参考：仓库根目录下的 `DATA_SCHEMA.md`）。这些文件是唯一的权威数据源；它们由原版 XML 转换而来，原版 XML 原封不动地保留在 `../xml/` 中。模组会合并到这些文件中（见 `MODDING.md`）。Markdown 文件不会被打包。
